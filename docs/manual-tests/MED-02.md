# MED-02. «Медиа беседы» — режим вместо ленты

Статус: ⏳ (ручная проверка — владелец: демо `--demo`, затем живой ящик)

Подготовка: `cargo run -p postman-gpui -- --demo 2000`; беседа «Пилот «Маяк»: материалы» — в «Архиве» (или поиск
`Маяк`). В живом ящике — любая беседа из нескольких писем с вложениями и ссылками.

1. Открыть письмо беседы: под шапкой — вкладки-режимы «Беседа · 4 письма» и «Медиа беседы · N» с подчёркиванием
   у выбранной; над лентой строка «В беседе … файлов, … картинок и видео, … ссылок — Открыть «Медиа беседы» →».
2. Щелчок по «Медиа беседы», по строке-сводке или Ctrl+L (вне полей ввода; палитра — «Беседа: файлы, ссылки,
   медиа») — вместо ленты режим: поиск во всю ширину, вкладки «Файлы, Медиа, Ссылки, Контакты, Встречи» со
   счётчиками, справа вид «Список | Галерея | Таблица». Esc или «Беседа» — назад к ленте; справа от вкладок —
   подсказка «Esc — назад к беседе».
3. Пока тела писем докачиваются — строка «Загружено N из M писем» с полосой хода; пришли — строки нет, счётчики
   выросли. Беседа, где тел ещё нет совсем, — «Письма ещё не скачаны».
4. «Файлы»: имя, тип и размер, значок канала, кто и когда; файл, пересланный дважды, — «×2», щелчок разворачивает
   письма с ним, у каждого «К письму». Щелчок по строке — рамка акцента и голубая полоса «Выбрано: …» с «К письму»:
   открывается письмо, режим — снова «Беседа».
5. «Медиа» — галереей по умолчанию: плитки картинок и видео (у видео — метка), картинки подписей и пиксели
   отслеживания не показаны. «Список» и «Таблица» — те же элементы; вид запоминается на вкладку.
6. «Ссылки»: домен, текст, кто и когда; метки «Отписка», «Счётчик переходов»; ссылок из цитат нет. «Таблица» —
   столбцы «Название, Кто, Когда, Канал». Выбрать ссылку → «Открыть» — браузер; подозрительная (текст похож на
   другой адрес) — красный значок и метка, «Открыть» даёт красную строку «…ведёт сюда: адрес» с «Открыть всё равно»
   и «Отмена»; Esc снимает строку.
7. «Контакты»: участники беседы (имя, адрес, число писем, «я» — меткой), визитка vCard — с меткой «визитка» (не
   разобрана воркером — «ещё не разобрана»). Выбрать участника → «Написать» — новое письмо ему.
8. «Встречи»: приглашение беседы — тема, время, место, мой ответ меткой («Принято», «Под вопросом», «Отклонено»,
   «Нет ответа»); отменённая — перечёркнута, метка «Отменена».
9. Поиск: набрать часть имени файла или домен — счётчики всех вкладок по найденному; ничего — «По «…» ничего» и
   «Сбросить поиск». Пустая вкладка видна со счётчиком 0 — «Здесь пока пусто».
10. Беседа канала (демо-канал, «Анна Смирнова»): те же вкладки-режимы под шапкой; «Контакты» — участники
    беседы, «Файлы» и «Медиа» — уже загруженные вложения со значком канала, «К письму» — назад к ленте.
11. Другая беседа — режим снова «Беседа», поиск пуст. Тёмная тема — те же экраны (`--theme dark`).
